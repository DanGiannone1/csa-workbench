# Evaluation Guide Documents

This folder contains shareable AI agent evaluation guides and repo-specific evaluation notes.

## Document Authority

- `AI_Agent_Evals_Team_Guide_General.docx` is the current broad-audience guide for teams outside this repository.
- `AI_Agent_Evals_Team_Guide_CSA_Workbench.docx` is the current CSA Workbench-specific guide for repo users and developers.
- `AI_Agent_Evals_Team_Guide.docx` is the original guide retained as a source/history document.

Superseded CSA Workbench drafts are intentionally not retained in this folder. Use the highest CSA Workbench version present here as the repo-specific authority.
